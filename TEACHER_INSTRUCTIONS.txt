HOW TO RUN ON YOUR PC:
------------------------------------------------------------------------

OPTION 1: One-Click Launcher (Recommended for Windows)
1. Double-click "START_FINCULATOR.bat".
2. It will automatically start the local server and open http://localhost:3000 in your browser.

OPTION 2: Manual Terminal / Command Line Launch
1. Open Terminal / PowerShell / Command Prompt in this folder.
2. Run:
      python server.py
3. Open your web browser and navigate to:
      http://localhost:3000

OPTION 3: Direct Browser Open (Offline / Static Mode)
1. Double-click "index.html" or open it in Google Chrome / Edge / Firefox / Safari.
